# HW2: Interactive Bear

An interactive Arduino plushie that changes its mood based on user interaction and environmental light levels.

## Features

- **Neutral Mood (Green):** The toy starts with a neutral mood score of 10.
- **Happy Mood (Blue):** Press the push button to increase the mood score.
- **Sad Mood (Red):** If the toy is left untouched for more than 5 seconds, its mood score gradually decreases.
- **Bonus Feature – Afraid of the Dark:** A photoresistor detects low light levels and doubles the mood decay speed, making the toy lose mood twice as fast in darkness.

## Components

- Arduino Nano
- RGB LED (common-anode)
- Push button
- Photoresistor (LDR)
- Resistors
- Breadboard and jumper wires
